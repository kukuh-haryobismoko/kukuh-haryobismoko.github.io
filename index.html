SayaKaya Analytics — full web platform

Internal analytics web platform for SayaKaya's mutual-fund business, built end to end on my own. It replaces ad-hoc BigQuery requests with self-serve dashboards: every number is recomputed from the data warehouse when the page opens, nothing is typed in by hand. Teams track AUM, transactions, investors, revenue, partner sharing, marketing attribution and the app funnel, and run operations such as reconciliation against the custodian feed and scheduled statement emails.

What it does
54 tabs in 8 groups: AUM and revenue trends, investor portfolios cross-checked across independent data sources, transaction search, custodian reconciliation, referral and booth-event tracking, product funnel, KYC and subscription analysis, push and app health. Exports to CSV, Excel, PDF and Google Sheets.
Automation
Scheduled e-statement and fund-performance emails via Amazon SES and a GitHub Actions cron, with OTP confirmation, open/click tracking and an email-recap tab.
AI & forecasting
The Ask assistant turns plain-language questions into read-only SQL with Claude and picks the chart. BigQuery ML forecasts AUM and transaction volume (ARIMA_PLUS) and scores churn risk (logistic regression). AI Insights runs a weekly summary, anomaly scan, churn action list and data-quality check.
Architecture
Plain HTML/CSS/JS front end with Chart.js, no build step, on GitHub Pages. Node.js/Express API ported to a Supabase Edge Function (Deno/TypeScript) with identical SQL. BigQuery holds the data; Supabase Postgres holds accounts, sessions, schedules and logs. Automated tests render every tab with sample data.
Guardrails
Per-account tab permissions, hashed passwords, 7-day sessions, sensitive columns stripped from every result, single-statement read-only SQL for SQL lab and Ask, a per-query BigQuery byte cap and an activity log.
